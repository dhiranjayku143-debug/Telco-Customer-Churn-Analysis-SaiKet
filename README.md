# Customer Segmentation Visualization & Advanced Analysis

**Internship:** Business Analysis Internship at **SaiKet Systems**
**Project:** Telecom Customer Churn Analysis
**Tool:** WPS Spreadsheet / Microsoft Excel
**Dataset:** Telco Customer Churn (7,043 customers, 21 columns)

## Project Overview
This project analyzes customer churn in a telecom company and provides insights to improve customer retention.

## Key Findings
- Total customers: 7,043 | Churned: 1,869 (26.5%) | Retained: 5,174 (73.5%)
- Gender has almost no effect on churn (Female 26.9% vs Male 26.2%).
- Most customers pay $20-30 (basic plans) or $70-100 (premium plans) per month.
- Churn is highest among new customers (0-12 months) with high bills ($100-120): 76.5%.
- Churn is lowest among long-term customers (61-72 months) with low bills.

## Recommendation
Offer retention discounts and better support to high-bill customers in their first year.
